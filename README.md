# text-transformer-mini

A tiny library to convert text to uppercase, lowercase, and title case. Useful for standardizing text input for processing.

> This project is useful for developers who need to standardize text input for processing, such as in data cleaning or preprocessing tasks.

## Features

- Contains functions to convert text to uppercase, lowercase, and title case
- Tests the text transformation functions to ensure they work as expected
- Verified by tests: pytest will verify that the functions correctly transform text to uppercase, lowercase, and title case.

## Requirements

- Python 3.11+
- Stack: python, pytest

## Install

```bash
git clone <this-repo>
cd text-transformer-mini
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python -m pytest
```

Example output:

```text
>>> from text_transformer import to_uppercase, to_lowercase, to_title_case
>>> to_uppercase('hello world')
'HELLO WORLD'
>>> to_lowercase('HELLO WORLD')
'hello world'
>>> to_title_case('hello world')
'Hello World'
```

## Tests
